- **事实**（11-19 用户截图的官方权益页）：免费版 1080p 30 帧；VIP（238 元/年）含「多屏控多屏、无线副屏、虚拟屏、超级屏」。2026-12-01 起生效
- **对外立场**（主人定，三版才定稿，见 [[feedback-doc-writing]]）：「若你恰为 UU远程 VIP 用户，欢迎一试」+ 独立社区项目、与 UU远程 无商业关联、不必为 Snug 专门开通。主次别颠倒，别写得像托。README 顶部 IMPORTANT 框、致谢「三年免费 / 支持商业化（作者已开通 VIP）」、2.7.0 GitHub Release 页均已按此改；应用内更新日志与 v2.7.0 标签说明仍是旧说法「面向已开通 VIP 的用户」，主人没要求改
- **待实测**（12-01 后用免费账号）：免费版能否在 UU 屏幕菜单里切到非主屏；设为主屏常驻后免费版是否照样直接进 Snug 的屏（UU 每次连接推主屏，推测可行，未验证）。实测前不写进 README，也不包装成绕开 VIP 的办法
- **横向扩展**：主人赞成支持其他远控（#35 问 RustDesk），已回复「在评估」。下一步是派小 workflow 读 RustDesk 源码，查清四点：Mac 上如何察觉连接、连上推哪块屏/认不认中途新增的屏、手机触控到 Mac 是什么事件、能否读到控制端设备。Snug 绑 UU 的四处（连接察觉、推流屏判断、手势只接管 UURemoteServer、控制端识别）抽成接口——有了真实的第二个用例才抽象

**Why:** UU 收费改变了 Snug 的用户前提，措辞稍有偏差就像替 UU 推广。
**How to apply:** 提到 UU 收费一律照上面的立场写；12-01 后提醒主人做免费版实测；RustDesk 评估在主人点头后再起。
